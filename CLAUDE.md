# Lively Foundation Project Context

## Tech Stack
- Frontend: Next.js (React) or React + Vite
- Styling: Tailwind CSS (Mobile-first, vibrant/lively design)
- Core Features: Donation portal, Projects page, Gallery, Landing Page,event calendar, volunteer sign-up, 

## Design Guidelines
- Vibe: Energetic, welcoming, and community-focused
- Primary Colors: Vibrant accent colors (e.g., bright orange/coral or deep teal)
- Animations: Smooth transitions for high user engagement
